# FORWARD Software Repositories  
This repository contains all software codebases for the FORWARD system.

## AMB82_Cam_Code: Software for the Ameba Camera Board  
* Driver software for the Ameba AI camera board, including functionality to connect to the locally hosted FORWARD network, process camera data, identify objects of interest, and transmit detection data to the MCU over Wi-Fi.

## Cam_Network_Stream: Visualization Software for the Ameba Camera Board  
* Generates a network stream of camera data to visualize AI detection results, including identified objects, bounding box regions, and confidence scores.

## ESP_Embedded_Code: Software for the ESP32 Microcontroller  
* Core embedded software for the FORWARD system, responsible for hosting the local network for data transfer, interfacing with sensors, processing environmental data, making navigation decisions, and driving motors for system navigation.
